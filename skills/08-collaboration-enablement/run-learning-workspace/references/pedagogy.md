# 持久化学习工作区教学法

## 学习目标

围绕使命同时培养：

- 知识：来自高质量、可追溯来源的必要概念。
- 技能：通过练习、反馈和真实任务形成可迁移能力。
- 智慧：在合适时通过实践者、社区或真实环境检验判断。

只讲完成当前技能所需的知识。不要用信息量代替学习成果。

## 难度与记忆

区分当下熟悉感和长期保持：

- 知识获取阶段减少无关难度，保护工作记忆。
- 技能练习使用主动检索，让用户先尝试再看答案。
- 跨会话安排间隔练习；需要辨别相近技能时使用交错练习。
- 立即反馈可纠正动作，但不要提前泄露答案。
- 流畅回答不等于掌握；只有可观察应用证据才进入学习记录。

## 最近发展区

选择用户凭现有能力加少量支持即可完成的下一步：

1. 从使命推导当前最有价值的能力。
2. 从学习记录确认已掌握前置知识。
3. 选择一个短时可完成、结果可观察的小任务。
4. 太容易时减少提示或增加迁移；连续失败时缩小任务并补前置知识。

## 课程设计

- 每课只设一个成果和一个紧凑反馈回路。
- 先给完成任务所需的最小解释，再让用户操作、回答或判断。
- 练习答案的格式和长度不要无意泄露正确选项。
- 链接主要来源、相关课程和速查资料；不在课程中复制整份 reference。
- 把可复用布局、组件或交互放入 assets，保持课程视觉一致。

## 来源与社区

优先使用一手资料、同行评审研究、官方文档或公认专家资料。给每个资源写明覆盖内容和何时使用；删除已证伪、浅薄或偏离使命的来源。

只有真实经验比资料解释更重要时才推荐社区或实践活动。说明目的、成本和风险；用户不愿参与时停止推荐并记录偏好。
