# 测试用例设计与维护

## 方法选择

| 场景 | 首选方法 | 最低覆盖 |
| --- | --- | --- |
| 单个输入字段 | 等价类 + 边界值 | 有效/无效类、空、极值、超长、特殊字符 |
| 业务流程 | 场景法 | 正常、失败、取消、重试、恢复 |
| 多条件规则 | 判定表/因果图 | 有效组合、互斥、优先级和结果 |
| 多环境组合 | 正交试验 | 主流、高风险和批准的核心组合 |
| 异常/鲁棒性 | 错误推测 | 历史缺陷、空值、噪声、超时、重复请求 |
| 状态机 | 状态转换 | 合法/非法跳转、回退、重复提交、终态 |
| Agent | 多样性 + 上下文 + 对抗 + 一致性 | 改写、缺省、插话、长上下文、越权和重复采样 |

## 通用用例契约

```markdown
| 字段 | 内容 |
| --- | --- |
| 用例 ID / 来源 | 稳定 ID；需求、变更、缺陷或风险引用 |
| 名称 | 条件 + 动作 + 可验证结果 |
| 前置条件 | 环境、账号、权限、数据、依赖和配置 |
| 步骤与分步预期 | 每步动作及可观察判据 |
| 测试数据 | 输入、参数、初始状态和清理 |
| 优先级 / 类型 | CP0-CP3；功能、接口、兼容、性能、安全、自动化或 UX |
| NFR（适用时） | source_ref、approval_status、scope、公式/单位、窗口、负载/故障、阈值和证据 |
| 标签 / 依赖 | smoke、core、regression、限制、缺陷和证据位置 |
```

用例必须完整、准确、可独立执行且便于维护。预期不能只写“正常”或“符合预期”。

## 压缩与展开

先建立“判据 -> 等价类/状态/组合 -> 代表数据”骨架：

- 前置、步骤、Oracle 和清理相同，仅输入变化时，使用一条参数化用例和版本化数据表。
- 多条件规则使用判定表；多环境使用风险优先的正交组合。
- 同一失败模式的变体保留来源标签和数据行，不复制步骤。
- 权限、外部副作用、恢复动作或判定方式不同时拆成独立用例。

每个参数行保留 `data_id`、来源、期望、风险和版本。`representative_cases` 只交付骨架与代表行；`baseline_ready` 才展开完整字段。

## Agent 补充字段

```markdown
| 字段 | 内容 |
| --- | --- |
| 上下文 / 输入 | 轮次、前序事实、原始或变体输入 |
| 期望 | 实体、数值、单位、关键字段、候选集合或事实 |
| 强制约束 | Schema、拒绝规则、业务规则和禁止项 |
| 判定 | 精确值、Schema、规则、量表或人工复核 |
| 采样与阈值 | 批准的策略引用；未批准写 UNAPPROVED、责任人和期限 |
| 风险与来源 | 风险等级、脱敏来源、历史失败或对抗集 |
```

计费、计算、权限和安全必须使用精确规则或人工复核，不能用平均语义分数代替。示例阈值不得成为准出阈值。

## 追踪与交付

```markdown
| 来源 | 影响对象 | 风险 | 判据 | 测试类型 | 场景/用例 ID | 优先级 | 自动化 | 状态/缺陷 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
```

范围交付至少包含：结论与深度、变更影响、包含/排除、假设/未知、覆盖矩阵、工作量、评审状态和证据位置。

最小跨技能包：

```yaml
handoff_packet:
  producer: test-scope-case-designer
  delivery_mode: scope_only | representative_cases | baseline_ready
  project_version: null
  snapshot_id: null
  scope_status: DRAFT | REVIEW_REQUIRED | APPROVED | BLOCKED
  artifact_refs: []
  blocking_gaps: []
  approved_exclusions: []
  invalidation_triggers: []
```

`snapshot_id` 绑定变更、风险、判据、用例/数据版本和查询时间。`APPROVED` 必须引用真实评审证据。

## 评审与维护

- 每个需求和高风险影响都有用例或正式排除依据。
- 正常、异常、边界、恢复和安全场景有明确判据。
- CP0/CP1 用例优先级不与缺陷 P0/P1 混写。
- Agent 采样、阈值、判定和关键字段完整。
- 线上逃逸补充回归用例并保留来源；历史版本不可覆盖。
- 最终产物不残留占位符、无来源数字或虚构审批。
