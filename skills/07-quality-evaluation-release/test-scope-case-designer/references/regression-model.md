# 回归层级模型

项目策略优先。范围 owner 选择层级并记录来源、适用范围、排除、风险和批准状态；执行门禁不能自行缩减层级。

| 层级 | 最小语义 | 典型适用 |
| --- | --- | --- |
| `smoke` | 启动/入口、核心 happy path、关键 API 或工具调用 | 候选版本快速可信度检查 |
| `core` | smoke、变更/修复点、高风险用例、受影响上下游和常见失败路径 | 常规迭代或紧急修复 |
| `full` | core、全部批准用例、兼容、边界、异常、恢复和适用 NFR | 大版本、重构、高风险迁移或长期未发布 |

所有层级都覆盖变更点、修复点和直接影响。选择最小充分层级；排除必须有证据、剩余风险、责任人和重新纳入条件。不得用固定条数、比例或时长替代风险证据。

输出记录版本、层级、包含/排除、用例与数据版本、环境、判据、批准来源、剩余风险和失效条件，供 `$test-execution-governor` 的 `lifecycle_gate` 消费。
