# 发布门禁与关闭

发布方式、阶段、流量选择、观察窗口和审批角色全部来自当前批准的 release profile；仓库不提供默认比例、时长或固定组织顺序。

## 前置证据

- 版本、变更、影响、风险、批准测试范围与 `EXIT_GATE` 准出可核验。
- 配置、数据迁移、Agent Prompt/模型/工具/知识/Schema 和恢复资产已冻结。
- 发布、threshold、rollout、监控、值守、审批与回滚 profile 完整且适用。
- 预发布核心哨兵、产品验收、缺陷与遗留风险有当前证据。

## 决策

| decision | 语义 |
| --- | --- |
| `GO` | 全部硬门禁满足，发布方式、观察和恢复已确认 |
| `CONDITIONAL_GO` | 硬门禁满足，仅有经批准的非阻塞风险和补偿 |
| `NO_GO` | 尚未改变生产，且存在可信硬失败或不可接受风险 |
| `BLOCKED` | 证据、审批、监控、环境或 profile 无法核实 |
| `ROLLBACK` | 生产变更已开始并命中批准的硬回滚规则 |

上游状态不得静默放行：测试 PAUSED/BLOCKED 或 Agent REVIEW_REQUIRED/BLOCKED 映射为 `BLOCKED`；可信 FAIL 在部署前映射为 `NO_GO`，生产变更开始后按当前硬规则决定 `ROLLBACK`。接受风险只有经发布责任 owner 重新确认后才可能成为 `CONDITIONAL_GO`。

Agent 在线 `OK` 只表示当前窗口无新增阻塞；`WATCH` 保持阶段；`STOP_RECOMMENDED` 先冻结推进，再按批准规则判定，不能视为已回滚。总体平均不能掩盖核心分片、工具、数据或安全失败。

## 阶段与关闭

每阶段验证核心业务、错误/延迟/资源、Agent、数据、兼容、安全、隐私、日志/Trace 和告警，并记录版本、流量/人群、窗口、样本、阈值、异常、确认和证据。生产只允许发布授权范围内的低风险哨兵与被动遥测。

关闭要求核心验证和全部阶段门禁完成、观察满足批准 profile、无未处置硬失败、记录归档、遗留风险与长期监控已交接。长期 SLO 窗口未结束时只能报告当前发布观察结论，不能声称长期 SLO 已完成。
