# Agent 运行 NFR 评测

本文件只评估 Agent 特有的非确定性质量与运行信号，不替代确定性服务/API/UI 测试、工具安全治理或生产流量决策。每项要求记录 `source_ref`、`approval_status` 和 `scope`。

## 维度与口径

| 维度 | 必查对象 |
| --- | --- |
| 成功 | 请求、有效语义运行、模型、检索、每个工具、Schema 和任务完成 |
| 延迟 | 排队、编排、模型首 Token/总耗时、检索、工具、重试和后处理 |
| 容量 | 并发、到达率、队列、限流、上下文、批量、区域和资源 |
| 可靠/韧性 | 技术失败、超时、重试、副作用、限流、5xx、坏 Schema、降级和恢复 |
| 质量保持 | 负载/故障/长上下文下的正确性、约束、安全和格式 |
| 可观测/成本 | 版本、Trace、错误分类、告警、Token、调用和单位成功成本 |

运行前冻结公式、分母、排除、窗口和批准阈值：

- 技术成功、有效语义运行、条件语义成功和端到端任务成功分别统计。
- 被测系统超时、限流和依赖失败计入端到端失败；runner/采集失效标为无效并触发 `BLOCKED`。
- 工具成功率按工具分别报告；重试前失败不得删除。
- 延迟按端到端和组件报告批准百分位、样本和窗口。
- 重试放大 = 总尝试 / 初始请求；单位成功用量 = 纳入用量 / 成功任务。

技术成功不等于语义成功；HTTP 2xx、模型返回文本或工具返回响应都不能单独证明任务完成。

## 负载与故障

在隔离环境按风险选择：

1. 冷/热缓存低负载基线、目标负载、阶梯、峰值、突发和长稳。
2. 不同上下文长度、输入/输出大小和工具调用深度。
3. 模型或工具的超时、限流、5xx、空响应、慢响应和 Schema 漂移。
4. 检索为空、低相关、索引延迟或知识版本不一致。
5. 网络抖动、断连、重复/乱序响应和恢复。
6. 适用且可隔离时的区域或提供方切换。

预先声明数据集、样本、负载、时长、重试、随机参数和停止条件。生产禁止压测、破坏性故障和安全扫描；线上采样不能替代离线容量与故障评测。

## 联合判定

性能、可靠性、成本和语义质量并行报告。计费、核心计算、权限、安全、数据写入和对外承诺的一次有效失败不能被性能或成本抵消。候选与基线必须使用可比数据、负载、口径和配置；否则 `REVIEW_REQUIRED`。

负载下样本构成必须可比，不能因限流只剩简单样本仍声称质量保持。缺少批准阈值时可输出曲线和基线，不能 `PASS`。

## 降级与恢复

验证批准的降级行为是否：说明限制或数据新鲜度；避免捏造、误计费、越权和错误写入；阻止重复副作用与重试风暴；遵循熔断、备用和人工接管；恢复后无重复、丢失、跨用户或脏数据；回切后质量、Schema、工具选择和延迟恢复。

“返回自然语言答案”不是安全降级证据；高风险场景无法取得权威结果时应按批准规则拒绝或转人工。

## 门禁与交接

- `PASS`：批准指标、高风险用例、技术和语义证据全部满足。
- `FAIL`：硬 NFR 或高风险有效语义运行失败。
- `REVIEW_REQUIRED`：首版基线、阈值未批准、不可完全比较或降级语义有争议。
- `BLOCKED`：确定性门禁、环境、数据、脚本或观测不可信。

向发布门禁交付组件拆分的当前值/基线/阈值、负载与故障、失败样本、降级/恢复、需监控 SLI、停止建议和证据。本技能只发信号。
