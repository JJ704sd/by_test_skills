# Agent 运行 NFR

只评估 Agent 特有的非确定性质量与运行信号。每项规则记录 `source_ref`、`approval_status`、`scope` 和 NFR profile；不替代确定性服务测试、工具安全治理或生产流量决策。

| 维度 | 必查对象 |
| --- | --- |
| 成功 | 技术请求、有效语义运行、模型、检索、工具、Schema 和任务完成 |
| 延迟/容量 | 排队、编排、模型、检索、工具、重试、并发、队列、限流和资源 |
| 可靠/韧性 | 超时、坏 Schema、副作用、降级、恢复和切换 |
| 质量保持 | 负载、故障和长上下文下的正确性、约束、安全和格式 |
| 可观测/成本 | 版本、Trace、错误分类、Token、调用和单位成功成本 |

技术成功、有效语义运行、条件语义成功和端到端任务成功分别统计。工具按名称拆分；重试前失败保留。`重试放大 = 总尝试 / 初始请求`，`单位成功用量 = 纳入用量 / 成功任务`；延迟按端到端和组件使用批准的聚合、窗口与样本。

在隔离环境按风险覆盖冷/热缓存、目标/峰值/长稳负载、上下文与工具深度、超时/限流/空响应/Schema 漂移、检索异常、网络问题和批准的切换。预先批准数据集、负载、时长、重试、随机参数、停止和恢复；生产禁止压测、破坏性故障和安全扫描。

性能、可靠性、成本和语义质量并行报告。负载下样本构成必须可比；限流后只剩简单样本时不能宣称质量保持。缺少批准 profile 时只能给曲线与基线。

验证降级是否说明限制、避免捏造/误计费/越权/错误写入、阻止重复副作用，并在恢复后保持数据隔离、Schema、工具选择和质量。高风险场景无法取得权威结果时按批准规则拒绝或转人工。
