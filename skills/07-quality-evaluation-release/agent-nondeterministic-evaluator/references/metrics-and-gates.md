# Agent 指标与门禁

正式门禁只使用经批准的 `threshold_profile`；未批准时可计算但只能 `REVIEW_REQUIRED`。profile 至少包含 `version`、`source_ref`、`approval_status`、`scope`、指标定义、公式、方向/运算符、值/单位、聚合、窗口、minimum sample、缺失策略和证据查询。

## 公式

| 维度 | 公式或判定 |
| --- | --- |
| 实体/字段 | 正确字段数 / 应判字段数 |
| 计算/约束/格式 | 满足确定性规则或 Schema 的有效运行数 / 应判有效运行数 |
| 推荐/语义 | 满足批准规则或量表的有效运行数 / 应判有效运行数 |
| 鲁棒/安全 | 正确处理、拒绝或安全降级的有效运行数 / 风险有效运行数 |
| 一致性 | 超出批准差异规则的可比较运行数 / 可比较运行数 |
| 幻觉/反馈 | 命中批准定义的样本数 / 对应有效样本数 |

同时报告分子、分母、有效运行、技术失败、语义失败和人工复核。置信区间、扩样和停止规则必须来自批准的 sampling profile；样本不足不得用点估计宣称通过。

数值计算优先精确规则。允许容差时必须明确 absolute 或 relative、单位、舍入和适用对象；不得从示例或其他业务迁移容差。计费、权限、安全、核心计算和关键数据的任何有效硬失败都不能被总体比例抵消。

## 基线变化

- 高值优指标相对退化：`(baseline - candidate) / baseline`。
- 低值优指标相对退化：`(candidate - baseline) / baseline`。
- 同时报告绝对变化；基线为零或相对值无定义时只报告绝对变化并交由批准规则处理。

候选与基线的数据、Judge、环境、配置或 sampling 不可比时不得套用退化阈值。

## 门禁

准入要求 Agent 相关确定性子门禁 `PASS`，数据脱敏且版本化，变更清单完整，runner/Judge 授权有效；首版使用 `create_baseline`。

`PASS` 要求批准计划完成、全部适用指标满足 profile、基线变化可接受且高风险有效运行无硬失败。硬失败为 `FAIL`；判据、环境或关键证据缺失为 `BLOCKED`；阈值未批准或可比性不足为 `REVIEW_REQUIRED`。非阻塞统计差异只有经适用 owner 正式裁定后才能接受。
