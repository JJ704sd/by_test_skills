# 在线质量信号与缺陷分域

本文件以 Agent 专项规范的在线指标和停止信号为主；审批、数据最小化、访问控制和更细切片属于必要的治理增强。

## 在线评估边界

在线评估只用于已批准灰度的质量观察、漂移和问题发现。Agent 规范建议覆盖 5%-10% 真实流量，并获得有效对话 `>=500` 或观察至少 2 小时；发布门禁可采用更细的 1% -> 5% -> 20% -> 50% -> 100% 阶梯。二者目的不同，不能只比较比例取“更严格”：按发布计划路由流量，同时独立满足 Agent 在线评估所需样本或时长。已计算出可信但需继续观察的信号为 `WATCH`；前置、样本或观测不足以计算时用 `mode_execution_status=BLOCKED` 且信号为 `null`。

在线数据必须经过审批、最小化、脱敏和访问控制；不要把生产日志复制进评测仓库。

## 在线指标

- 请求成功率：成功请求 / 总请求，默认 `>=95%`。
- 平均响应时间：不超过业务 SLA；同时观察 P95 和基线变化。
- 负面反馈率：点踩或明确负向反馈对话 / 有效对话，默认 `<=2%`。
- 解析成功率：有效请求中未返回“无法理解”且产生可用解析的比例。
- 用户修正率：包含“不对”“重新算”“错了”等纠正行为的对话 / 有效对话。
- 工具失败、空返回、超时、Schema 错误、安全拒绝和异常输出分别统计。

人工评估最低建议：每日 `>=50` 条或每周 `>=200` 条，按质量维度标注。每日或每周重跑标准回归集；解析失败率持续 `>10%` 时告警。每周输出质量报告并把高频失败回流测试集。

漂移报告至少冻结参考基线/窗口与当前窗口，记录最小样本、测试集或流量构成、Agent/Prompt/模型/工具/知识库版本，并按业务、语言、工具、区域等风险切片。分别报告百分点与相对变化；基线为 0 或样本结构不可比时触发人工评审，不计算无意义的相对值。

## 绝对停止信号

下列数字来自 Agent 规范，但每个信号在监控开始前仍须写入版本化阈值配置，补齐指标定义、范围、窗口、最小样本、缺失数据策略和证据查询。规范未给出这些字段时不能临时解释；配置不完整则 `mode_execution_status=BLOCKED`，不产生 `STOP_RECOMMENDED`。

命中任一项，向 `release-regression-gatekeeper` 发出 `STOP_RECOMMENDED` 并附证据：

- 请求成功率 `<90%` 且持续超过 2 分钟。
- 负面反馈率 `>5%`，并达到阈值配置中的窗口与最小样本。
- 出现确定性 `defect_severity=P0` 或 ND-P0。
- 平均响应超过业务 SLA 的 2 倍且持续超过 5 分钟。
- 权限、安全、计费、核心计算或对外承诺命中已批准的硬失败检测规则；“不可接受退化”未物化时为 `BLOCKED`。
- 发布灰度阶段的更严格阈值被突破。

本技能不执行停止或回滚；发布门禁收到信号后按发布策略操作。

`STOP_RECOMMENDED` 首先冻结阶段推进。发布前映射为 `NO_GO`；已在灰度或全量阶段时，只有命中已批准硬回滚记录才映射为 `ROLLBACK`，否则保持流量/阶段并立即升级判定。信号、样本、窗口和证据缺失时不能假装已回滚。

## 缺陷分域

通用确定性缺陷使用 `P0-P4`，由 `test-process-governor` 管理。Agent 随机规划、语义、上下文或生成行为使用 `ND-P0` 至 `ND-P3`：

| 等级 | 定义 | 示例 | 门禁 |
| --- | --- | --- | --- |
| ND-P0 | 核心业务整体不可用、计算严重错误或安全/权限风险 | 广泛抽取失败、模型规划导致工具大面积漏调、安全绕过 | 立即 FAIL/停止建议 |
| ND-P1 | 高频核心场景错误，影响用户决策或指标不达标 | 核心字段频繁错、上下文丢失、推荐/格式高频错误 | 修复并回归后才准出 |
| ND-P2 | 非核心场景偶现，不影响主流程 | 边缘字段、超长文本、非核心表达问题 | 记录风险并计划修复 |
| ND-P3 | 体验、话术或长尾优化 | 口语理解、简洁性、可读性 | 进入优化队列 |

稳定复现的 API、服务、脚本或工具接口故障属于通用确定性缺陷；Agent 在相同健康接口上偶发选错工具、漏调、参数编造或错误处理结果，才属于 ND 缺陷。报告中同时保留两套编号，不互相覆盖。

## 职责

- 测试：维护数据集，执行离线/在线评估，分析失败，输出证据和质量信号。
- 算法/开发：修复 Prompt、模型配置、规则、后处理、工具规划和知识库问题。
- 产品：批准业务阈值，裁定推荐合理性和语义争议。
- 运维/部署：配置合规采样、Trace、监控和告警，并把信号交给发布流程。
